# まなびドライブ（プロトタイプ）

算数・漢字・英語の2〜4択問題に、進む道を選んで答える子ども向けブラウザゲーム。
3D描画には同梱のThree.jsを使います。アカウント登録や追加のインストールは不要です。

## ファイル構成

- `index.html` — 画面（ダブルクリックで開けます）
- `style.css` — デザインとスマホ画面の調整
- `app.js` — ゲーム進行、操作、採点、時計やブロックの描画、効果音
- `road-geometry.js` — 分岐道路の連続した外周と、車が通る経路
- `drive-3d.js` — 道路・車・追従カメラの3D描画
- `vendor/` — 同梱のThree.jsとそのライセンス
- `questions.js` — 問題データと算数の自動問題生成
- `manifest.webmanifest`, `service-worker.js`, `icons/` — PWAの設定とアイコン

## PCで試す（最も簡単）

展開したフォルダ内の `index.html` をブラウザで開いてください。
問題ファイルを `fetch()` で取り込まず `<script>` で読み込む構成なので、`file://` でも動作します。

**PC操作**：キーボードの `←` / `→` キー、またはマウスで選択肢をクリック。3〜4択では `1`〜`4` キーも使えます。

## スマホで試す（開発中）

PCとスマホを同じWi-Fiにつなぎ、PCでこのフォルダを開いて以下を実行します。

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

Windowsで `python` が使えない場合は `py -m http.server 8000 --bind 0.0.0.0` を試してください。
PC側で `ipconfig` と入力して、Wi-FiのIPv4アドレス（例：`192.168.1.10`）を確認します。

スマホのブラウザで `http://192.168.1.10:8000/` を開きます（アドレスは各自のものに変更）。
Windowsファイアウォールが通信を遮断していないことも確認してください。

**スマホ操作**：左右の標識、画面下部の左右ボタン、または道路部分の左右スワイプ。

## URLを公開する

GitHub PagesやCloudflare Pagesなどの静的サイトホスティングにフォルダの内容を配置してください。
HTTPSでアクセスするとPWAとしてインストールし、キャッシュしたゲームをオフラインでも遊べます。
家庭内LANの通常のHTTPではサービスワーカーが使えない場合があります（ゲーム自体は遊べます）。

## 問題を増やす

`questions.js` の `KANJI`, `ENGLISH_WORDS`, `ENGLISH_SENTENCES` 配列に追加してください。

漢字の例：

```js
{ id:'k1-yama', grade:1, kind:'reading', word:'山', answer:'やま', wrong:'かわ' }
```

英単語の例：

```js
{ word:'apple', meaning:'りんご', emoji:'🍎' }
```

英文の例：

```js
{ english:'I have a pen.', japanese:'わたしは ペンを もっています。' }
```

通常の数値・単語問題は回答位置を左右へランダムに振り分けます。A/Bを選ぶ問題は、Aを左、Bを右に固定します。

算数問題は、3桁以内の正の整数の足し算・引き算、九九と2桁×1桁、九九の範囲の割り算、ブロック・比較・時計を条件に従って**自動生成**します。
「時計を読む」「2つの時計から選ぶ」「何時間後か求める」を含みます。

漢字の「書き」は手書き入力ではなく、正しい字を**2択で選ぶ方式**です。

## このバージョンの仕様・制約

- 1ステージ10問。各問題の制限時間は10秒で、回答後や時間切れ後は約4秒で次の問題へ進みます（ボタンで早送りもできます）。4問目と8問目は3〜4択の交差点です。
- 漢字には、単漢字・熟語だけでなく、文中の空欄に入る漢字を選ぶ問題と、文中の漢字の読みを答える問題があります。出題文は `questions.js` の `KANJI_SENTENCES` に追加できます。
- 車はブルー・レーサーから始まり、3連続正解でレッド・レーサー、6連続正解でホワイト・バイク、9連続正解でゴールド・トラックが解放されます。解放した車はサイドバーから選べ、選択状態はこの端末に保存されます。
- ゲーム画面が見えていない間やタブが非表示の間は、回答時間を一時停止します。
- ライフ制・広告・アカウント登録はありません。3D道路の表示にはWebGLに対応したブラウザが必要です。
- 学習履歴はクラウドに送信せず、この端末のブラウザ内に科目別最高コイン、音声設定、解放した車と選択中の車を保存します（`localStorage`）。現状は個別問題ごとの記録機能はありません。
- 英語の読み上げにはブラウザ標準の `SpeechSynthesis` を使用します。声質や可用性は端末に依存します。
- `file://` ではPWAのサービスワーカーが使用できません。
- PWAキャッシュを更新するには、配布時に `service-worker.js` の `CACHE` 名を変更してください。

道路の形と車の経路を検査するには `node tests/road-geometry.test.js` を実行します。時計問題の正解選択肢は `node tests/questions.test.js`、オフライン用の資源は `node tests/service-worker.test.js` で検査できます。ローカルサーバーで `tests/road-preview.html` を開くと、上から見た道路と走行視点を切り替えられます。
